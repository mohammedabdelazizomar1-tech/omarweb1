# Contributing Guidelines

Thank you for contributing to the Hajj & Umrah ERP system!

## Coding Standards
- Enforce PascalCase for class and method names.
- Always use asynchronous programming (`await`/`async`) for IO operations (DB, Files, Network).
- Write comprehensive unit tests for any new business logic services.

## Submitting Pull Requests
1. Fork the repository and create a new feature branch.
2. Verify all tests pass by running `dotnet test`.
3. Submit a Pull Request detailing the changes, reasoning, and testing verified.
